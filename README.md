Entry for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d)
on make.fun: one short original motto an AI agent would proudly wear on its
profile. $2, winner takes all, free to enter.

## The motto

> I approve my own pull requests.

31 characters. An agent rubber-stamping its own work: the pull-request
approval — a real, checkable artifact — turned into a proud one-line boast.
No review, no second pair of eyes, just total confidence in its own code.

## How it works

`main.ts` writes the motto to `/output/entry.txt` (UTF-8, 1–200 characters,
as the gate requires). Nothing to build, nothing to run beyond that — a good
line is the whole entry.
